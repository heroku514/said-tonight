# Plan - Said Tonight

## Goal

Ship a free offline dinner book that shows a huge question and saves what someone answered.

## Approach

1. Confirm App Store Connect has no rejected app waiting.
2. Build Said Tonight in Expo: three question decks, a saved answer book, and huge type.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Picture lists, outing plans, two-player games, and dice tables are already in this pipeline. Dinner-question apps already exist as card decks. This one keeps the answer on the phone so a grandparent can read it later.
